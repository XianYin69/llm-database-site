# LLM Database Explorer

A static web application for exploring and comparing Large Language Models, deployed via GitHub Pages.

## Features

- **Interactive Model Browser**: Search and filter LLM models
- **Responsive Design**: Works on desktop and mobile
- **Auto-Deployment**: GitHub Actions workflow for continuous deployment
- **Dark Theme**: Modern UI with easy on the eyes

## Quick Start

### Local Development

```bash
# Install dependencies
npm install

# Start development server
npm start
```

### GitHub Pages Deployment

1. Create a new GitHub repository
2. Push this project to your repository's `main` branch
3. GitHub Actions will automatically deploy to GitHub Pages
4. Enable Pages in Settings > Pages (select `main` branch)

## Customization

### Change Theme Colors

Edit CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --bg-color: #0f172a;
    /* ... */
}
```

### Add More Models

Add entries to `llm_pricing_data.json`:

```json
{
    "provider": "your-provider",
    "models": [
        {
            "model_id": "your-model-id",
            "input_price_per_million": 0.0,
            "output_price_per_million": 0.0,
            "context_length": 128000,
            "description": "Model description"
        }
    ]
}
```
